# ❤️ — Personal Love Story

This is a free, static, mobile-first love-story website.

## Add your files

Put these files beside `index.html`:

- `music.mp3` — your background song
- `photo01.jpg` — first photo
- `photo02.jpg` — second photo
- `photo03.jpg` — third photo
- `photo04.jpg` — fourth photo

You can use PNG/WebP too by changing the names in `script.js`.

## Add your own lines

Open `index.html` and edit the paragraphs in the story and letter sections.



For a public GitHub Pages site, don't upload sensitive/private documents. Photos and personal messages are public to anyone with access to the URL.

## Important

The audio file is intentionally NOT included. Add your own `music.mp3` at hosting time.

For a production version, you can later add a real QR code, unique private URL, photo uploads, video, and a custom domain.
